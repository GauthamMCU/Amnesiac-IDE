# Amnesiac-IDE 🎯

A code editor suffering from severe short-term memory loss. Written code self-destructs the exact millisecond you run it.

## Basic Details

### Team Members
- Member 1: Gautham Thampy - Sree Buddha College of Engineering

### Project Description
Amnesiac IDE is a minimalistic, web-based code editor built with Flask and Monaco Editor. The primary gimmick: as soon as you press **Run Code**, your source code vanishes into thin air before the output reaches the console. If your code produces an error, you have to rewrite it entirely from memory.

### The Problem (that doesn't exist)
Standard IDEs retain your code after execution. This leads to code clutter, accidental hoarding of old scripts, and programmers relying too heavily on saving their work instead of training their photographic memory.

### The Solution (that nobody asked for)
Automated code erasure! By wiping the editor buffer instantly upon execution, Amnesiac IDE forces developers to achieve peak focus, memorize their syntax, and accept that code is ephemeral.
